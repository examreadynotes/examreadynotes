⚙️ Setup — EmailJS (Free, 200 emails/month)

Order confirmation receipts are sent automatically via EmailJS. Follow these steps once:

  1. Create a free account at emailjs.com and connect your Gmail.
  2. Create an Email Template. Set the Subject to: Order Confirmation – {{order_id}}
  3. In the template body, add one variable: {{{html_body}}} (triple braces so HTML renders correctly).
  4. Copy your Public Key from Account → API Keys, the Service ID, and the Template ID.
  5. Paste all three into the EMAILJS_PUBLIC_KEY, EMAILJS_SERVICE_ID, and EMAILJS_TEMPLATE_ID constants near the top of index.html.
